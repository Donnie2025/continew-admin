## 📋 使用步骤

### 第一步：准备飞书文件夹

1. **创建文件夹**：
   - 在飞书云文档中创建课节文件夹
   - 将PDF课节文件上传到文件夹中

2. **文件命名规范**：
   ```
   建议格式：01, K1U1L1 Hello.pdf
   支持中文：第一课 问候语.pdf
   ```

3. **获取分享链接**：
   - 右键点击文件夹
   - 选择"分享" → "复制链接"
   - 获得类似链接：`https://ai.feishu.cn/drive/folder/TEV8fJml3lsaj2dLBOUcxovanvc`

### 第二步：系统导入操作

1. **进入课节管理**：
   - 登录系统后台
   - 导航到"教育管理" → "课节管理"

2. **点击导入按钮**：
   - 在页面右上角找到"从飞书导入"按钮
   - 点击打开导入模态框

3. **填写导入信息**：
   - **选择教材**：从下拉列表选择目标教材
   - **飞书链接**：粘贴文件夹分享链接
   - **覆盖选项**：
     - ✅ 勾选：覆盖同名课节
     - ❌ 不勾选：跳过同名课节
   - **备注信息**：可选填写导入说明

4. **执行导入**：
   - 点击"确定"按钮开始导入
   - 系统将显示导入进度

## ⚠️ 注意事项

### 1. 文件格式要求
- **支持格式**：PDF文件（.pdf）
- **不支持**：Word、PPT、图片等其他格式
- **文件大小**：建议单个文件不超过50MB

### 2. 权限要求
- 飞书文件夹必须设置为**公开分享**
- 或者应用账号对文件夹有**访问权限**
- 确保链接有效且未过期

### 3. 网络环境
- 需要稳定的网络连接
- 确保服务器能访问飞书API
- 大量文件导入可能需要较长时间

### 4. 数据安全
- 导入前建议**备份现有数据**
- 测试导入功能时使用**测试教材**
- 重要数据操作前请**确认导入选项**

## 🔧 故障排除

### 常见问题及解决方案

1. **"无效的飞书文件夹链接格式"**
   - 检查链接格式是否正确
   - 确保是文件夹链接而非文件链接
   - 重新复制分享链接

2. **"获取飞书访问令牌失败"**
   - 检查App ID和App Secret配置
   - 确认应用权限设置正确
   - 检查网络连接

3. **"文件夹为空或无权限访问"**
   - 确认文件夹包含PDF文件
   - 检查文件夹分享权限设置
   - 确认链接未过期

4. **"部分文件导入失败"**
   - 检查文件格式是否为PDF
   - 确认文件名不包含特殊字符
   - 查看系统日志获取详细错误信息
