## ❌ 常见问题

### 问题1：配置未生效
**现象**：启动时没有飞书相关日志
**解决**：
```bash
# 检查配置文件是否存在
ls -la continew-webapi/src/main/resources/config/application-feishu.yml

# 检查主配置是否包含feishu
grep -n "feishu" continew-webapi/src/main/resources/config/application.yml
```

### 问题2：网络连接失败
**现象**：获取访问令牌失败
**解决**：
```bash
# 测试网络连接
curl -X POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal \
  -H "Content-Type: application/json" \
  -d '{"app_id":"cli_a9dccc613378dcda","app_secret":"86bUOn7UMgkzHpAMpxhkwcqKObR56Uhd"}'
```

### 问题3：权限不足
**现象**：文件夹为空或无权限访问
**解决**：
- 确认飞书链接有效
- 检查文件夹分享权限
- 验证应用权限配置
